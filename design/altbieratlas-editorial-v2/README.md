# Altbieratlas — Editorial-Konzept V2

Dies ist ein eigenständiger, nicht produktiver Designversuch. Er ersetzt weder bestehende Komponenten noch Produktions-CSS.

## Was bewusst anders ist
- Kein konstruiertes Logo-Signet: der Name selbst ist die Wortmarke.
- Wenige Farben, keine abgerundeten UI-Karten, keine Schatten, keine künstlichen Beer-Branding-Illustrationen.
- Typografie und redaktionelle Hierarchie führen; Foto ist dokumentarisch und regional.
- Mobile Layouts werden über eine einzelne Spalte gelöst.
- Kennzahlen sind ein read-only Snapshot aus dem Projektkontext und nur Platzhalter im Mockup. Nicht live verbunden.
- Brauerei-Links und Preise sind Demonstrationsinhalt, keine produktiven Routen oder verifizierten Preise.
